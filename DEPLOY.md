# Розгортання (деплой)

Сайт — це Node.js-сервер (не статичні файли). Йому потрібні:

1. хостинг із запуском Node.js (поточний варіант — Render.com, план Starter);
2. **постійний диск** для файлу бази даних (`DB_PATH=/var/data/data.sqlite`). Без нього всі дані,
   внесені через адмінку, зникатимуть після кожного деплою;
3. змінні оточення: `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`, `DB_PATH` (+ за потреби `SMTP_*`).

Готова конфігурація для Render — файл `render.yaml` (для **нового** розгортання).
Версія Node.js — не нижче 22.5 (потрібен вбудований модуль `node:sqlite`).

Повні інструкції щодо передачі, перенесення на інший акаунт, резервних копій і щоденної роботи
наведено в окремому документі про передачу проєкту (його не зберігаємо в публічному репозиторії).

## Пароль адмінки

Згенерувати хеш пароля: `npm run set-admin-password ВашПароль`, результат (`$2b$10$…`) вписати
у змінну `ADMIN_PASSWORD_HASH`. Якщо хешу ще немає, тимчасово підтримується звичайний пароль
у змінній `ADMIN_PASSWORD` (хеш має пріоритет).

## Резервні копії

Адмінка → «Копія»: завантаження та відновлення бази (`/admin/restore`).
